# Missing Store features

This page tracks gaps between the [server’s Store](store.md) and the
[observed EU catalog](store-eu-catalog.md). The EU catalog records the offers
and prices seen during research. Update this page as server support changes.

## Item and offer gaps

| Feature | What’s missing |
| --- | --- |
| Progressive styles | **Tiger Claw** for the WZ-114 is an example. The server supports permanent styles from the Store. Progressive styles still need ownership, per-style progression, fitting, and garage synchronization. See [Exterior](store-eu-catalog.md#exterior). |
| Editable styles | Applying a supported base style works. Applying custom changes to an editable style still needs a fitting and persistence workflow. |
| Personal Reserves | The one-hour **+100% Combat XP** and **+300% Free and Crew XP** reserves still need purchase, inventory, activation, expiration, and battle reward integration. See [Personal Reserves](store-eu-catalog.md#personal-reserves). |
| Bundles and sticker packs | The catalog records names and prices for equipment, consumables, directives, and exterior packs. Verified item quantities and checkout prices are needed for each bundle. The server sells supported individual items through their existing offers. See [Service](store-eu-catalog.md#service), [Exterior](store-eu-catalog.md#exterior), and [Items for Bonds](store-eu-catalog.md#items-for-bonds). |
| Rotating and seasonal offers | The Store has no schedule for timed offers, event catalogs, or promotional prices. The EU catalog intentionally focuses on regular offers. |

## Account products

- **WoT Plus Core and Pro** are outside the current Store scope. The server
  has no subscription lifecycle, entitlement, or benefit implementation.
  The [observed WoT Plus offers](store-eu-catalog.md#best) use EUR prices.
- **WoT Premium Account** supports purchase, extension, expiration, and
  garage status. Battle credit and XP bonuses, additional XP, premium
  missions, and the credit reserve still depend on battle settlement.
  See [Premium Account](store.md#wot-premium-account).
- **EUR checkout and paid gold packs** are out of scope. Admins can grant
  in-game gold through [Resources & Garage](admin.md#grants).
